# 알람 앱 - 창업/웹툰 뉴스 읽어주기 서비스 기술 명세서

알람 앱에 "울릴 때 창업/웹툰 최신 뉴스를 각 3개씩 가져와서 읽어준다"는 흐름을 **React + Supabase** 스택으로 구현하기 위한 기술 명세서.

## 1. 전체 아키텍처 흐름

```
[React 알람 앱]
     │ 알람 트리거 (setTimeout / Notification API)
     ▼
[localStorage 캐시 확인] ── 오늘자 뉴스 있음 → 캐시 사용, fetch 생략
     │ 캐시 없음
     ▼
[Supabase Edge Function: /fetch-news]
     │ (서버사이드 프록시, 네이버 API 키 은닉)
     ▼
[네이버 뉴스 검색 API]
     - query=창업 (display=3)
     - query=웹툰 (display=3)
     ▼
[Edge Function이 JSON 정제 후 응답]
     (title, summary, link, pubDate)
     ▼
[React 클라이언트]
     - 응답을 localStorage에 오늘 날짜로 캐싱
     - 뉴스 리스트 렌더링 (창업 3 + 웹툰 3)
     ▼
[Web Speech API (SpeechSynthesisUtterance)]
     - 6개 뉴스 title+summary를 순차 큐로 등록
     - 재생 (ko-KR)
```

핵심 포인트: **네이버 API 키는 브라우저에 절대 노출되지 않고 Edge Function 내부 환경변수로만 존재**, React는 Edge Function만 호출.

## 2. Supabase Edge Function (프록시 서버)

- 역할: 네이버 뉴스 검색 API 호출 + CORS 우회 + API 키 보호
- 위치: `supabase/functions/fetch-news/index.ts`
- 환경변수: `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` (Supabase 프로젝트 Secrets에 등록, 코드에 노출 안 함)

```ts
// supabase/functions/fetch-news/index.ts
import { serve } from "https://deno.land/std/http/server.ts";

const NAVER_CLIENT_ID = Deno.env.get("NAVER_CLIENT_ID")!;
const NAVER_CLIENT_SECRET = Deno.env.get("NAVER_CLIENT_SECRET")!;

async function searchNews(query: string, display = 3) {
  const url = `https://openapi.naver.com/v1/search/news.json?query=${encodeURIComponent(query)}&display=${display}&sort=date`;
  const res = await fetch(url, {
    headers: {
      "X-Naver-Client-Id": NAVER_CLIENT_ID,
      "X-Naver-Client-Secret": NAVER_CLIENT_SECRET,
    },
  });
  const data = await res.json();
  return data.items.map((item: any) => ({
    title: item.title.replace(/<[^>]*>/g, ""),
    summary: item.description.replace(/<[^>]*>/g, ""),
    link: item.originallink || item.link,
    pubDate: item.pubDate,
  }));
}

serve(async (req) => {
  const corsHeaders = {
    "Access-Control-Allow-Origin": "*",
    "Access-Control-Allow-Headers": "authorization, x-client-info, apikey, content-type",
  };

  if (req.method === "OPTIONS") {
    return new Response("ok", { headers: corsHeaders });
  }

  try {
    const [startup, webtoon] = await Promise.all([
      searchNews("창업"),
      searchNews("웹툰"),
    ]);

    return new Response(
      JSON.stringify({ startup, webtoon, fetchedAt: new Date().toISOString() }),
      { headers: { ...corsHeaders, "Content-Type": "application/json" } }
    );
  } catch (err) {
    return new Response(JSON.stringify({ error: String(err) }), {
      status: 500,
      headers: { ...corsHeaders, "Content-Type": "application/json" },
    });
  }
});
```

배포: `supabase functions deploy fetch-news`

## 3. React 클라이언트 연동

### 3.1 뉴스 fetch + 캐싱 훅

```tsx
// hooks/useNews.ts
import { useState, useEffect } from "react";
import { supabase } from "../lib/supabaseClient";

interface NewsItem {
  title: string;
  summary: string;
  link: string;
  pubDate: string;
}

interface NewsData {
  startup: NewsItem[];
  webtoon: NewsItem[];
}

const CACHE_KEY = "news_cache";

function getTodayKey() {
  return new Date().toISOString().slice(0, 10); // YYYY-MM-DD
}

export function useNews() {
  const [news, setNews] = useState<NewsData | null>(null);
  const [loading, setLoading] = useState(false);

  async function fetchNews(forceRefresh = false) {
    const todayKey = getTodayKey();
    const cached = localStorage.getItem(CACHE_KEY);

    if (!forceRefresh && cached) {
      const parsed = JSON.parse(cached);
      if (parsed.date === todayKey) {
        setNews(parsed.data);
        return parsed.data;
      }
    }

    setLoading(true);
    const { data, error } = await supabase.functions.invoke("fetch-news");
    setLoading(false);

    if (error) {
      console.error("뉴스 fetch 실패:", error);
      return null;
    }

    localStorage.setItem(CACHE_KEY, JSON.stringify({ date: todayKey, data }));
    setNews(data);
    return data;
  }

  return { news, loading, fetchNews };
}
```

### 3.2 TTS 재생 훅

```tsx
// hooks/useNewsReader.ts
export function useNewsReader() {
  function readNews(news: { startup: any[]; webtoon: any[] }) {
    const queue: string[] = [
      "창업 관련 최신 뉴스입니다.",
      ...news.startup.map((n) => `${n.title}. ${n.summary}`),
      "웹툰 관련 최신 뉴스입니다.",
      ...news.webtoon.map((n) => `${n.title}. ${n.summary}`),
    ];

    window.speechSynthesis.cancel(); // 기존 큐 초기화

    queue.forEach((text) => {
      const utterance = new SpeechSynthesisUtterance(text);
      utterance.lang = "ko-KR";
      utterance.rate = 1.0;
      window.speechSynthesis.speak(utterance);
    });
  }

  function stopReading() {
    window.speechSynthesis.cancel();
  }

  return { readNews, stopReading };
}
```

### 3.3 알람 트리거 연동 (알람 컴포넌트 내부)

```tsx
// 알람 울릴 때 호출
const { fetchNews } = useNews();
const { readNews } = useNewsReader();

async function onAlarmRing() {
  const news = await fetchNews();
  if (news) readNews(news);
}
```

## 4. 사전 준비 사항

- [ ] 네이버 개발자센터에서 애플리케이션 등록 → `Client ID`, `Client Secret` 발급
- [ ] Supabase 프로젝트 Secrets에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` 등록
  ```
  supabase secrets set NAVER_CLIENT_ID=xxx NAVER_CLIENT_SECRET=xxx
  ```
- [ ] Edge Function 배포 (`supabase functions deploy fetch-news`)
- [ ] React 프로젝트에 `@supabase/supabase-js` 설치 및 클라이언트 초기화

## 5. 향후 고도화 방향

- Web Speech API 음성 품질이 아쉬우면 Google Cloud TTS / 네이버 클로바 보이스로 교체 (Edge Function에서 TTS 오디오까지 생성해서 반환하는 구조로 확장 가능)
- 뉴스 캐시를 localStorage 대신 Supabase DB 테이블로 옮기면 여러 기기 간 동기화 가능
- 알람이 백그라운드(탭 종료)에서도 동작하도록 PWA + Service Worker 검토
